# Kernel Panic (haunted_terminal)

A short, browser-based horror game that plays out inside a fake Linux terminal.

Built with plain HTML, CSS and JavaScript. No dependencies, no build step.

**Content warning:** sudden loud audio, flashing visuals, screen shake, jump scares.

![img of the game](path/to/your/image.png)

## How to Play
Type commands into the prompt and press Enter.

| Command      | What it does                          |
|--------------|----------------------------------------|
| `help`       | Lists available commands              |
| `whoami`     | Shows who you're logged in as         |
| `ls`         | Lists files in current folder         |
| `cat FILE`   | Prints a file, e.g. `cat notes.txt`   |
| `clear`      | Clears the screen                     |
| `restart`    | Reloads the session from scratch      |
| `exit`       | Tries to leave (it won't be easy)     |

## Features
- Terminal-style typewriter output
- Files that unlock as you read them
- Random ambient "ghost" messages
- Web Audio API sound effects
- Screen shake, flicker, night-vision overlay, CRT shutdown finale

## Known Limitations
- Requires a user click/keypress before sound plays
- Fullscreen may be blocked by some browsers/embedded frames
- Progress isn't saved between sessions
